# `docs/referencias/` — material de terceiros

Não são produtos do projeto e **não se editam**. Estão versionados porque o projeto
depende deles para justificar decisões, e porque link externo quebra.

| Arquivo | Para que serve |
|---|---|
| `Cálculo IVS2012.docx` | **A metodologia-fonte.** Define denominadores, a regra `Dados_sig` e quais formas de saneamento são inadequadas |
| `indice_vulnerabilidade2012 (2).pdf` | O IVS-BH 2012 oficial, de onde vêm as duas dimensões e a referência de pesos 60/40 |
| `IBGE_Censo2022_Favelas_e_Comunidades_Urbanas.pdf` | A publicação que define Favela e Comunidade Urbana, usada na validação externa do índice |
| `guia_analises.docx` | O framework FIOCRUZ de análise exploratória, que estrutura o Notebook 02 |
| `Estudo Longitudinal da Saúde dos Idosos Brasileiros.docx` | O ELSI-Brasil, que define o recorte dos 70 municípios |
| `Plano de trabalho.pdf` | O cronograma da iniciação científica |
| `Plano_Artigo_Cientifico_IC_Preenchido.docx` | O plano do artigo, por fases |

**O livro da Enap não está aqui** — é material de terceiros com direito autoral e não
foi versionado. Anexe o PDF à sessão quando precisar conferir uma passagem; o estudo
dele está em [`../metodologia/`](../metodologia/).
