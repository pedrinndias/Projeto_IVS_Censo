**Regenerar** (depois das versões que ela lê):

```bash
node scripts/gerar_deck_versao.js analises_exploratorias/E4_populacao_em_risco
./.venv/bin/python scripts/verificar_versao.py analises_exploratorias/E4_populacao_em_risco
```
